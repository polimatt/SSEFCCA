# Van Krevelen Machine Learning Boundaries

Here, code is presented to create and share supervised classification models for compound class prediction based on elemental ratios (O/C, H/C, and N/C) derived from formula assignment of mass spectrometry data.

All material is present in the folder ```code```. Of special interest may be the pickled models contained in ```code/vk_definitions/models``` and the demos presented in ```code/demos```. The modules used can be found in the conda backup file ```code/vk_definitions.yaml```.
